# Data Viz Storytelling Task 4 - Superstore Sales Analysis

## 📌 Project Overview
This project is part of the 4th internship task for Data Visualization Storytelling. The objective is to analyze data from the Sample Superstore dataset using Power BI and provide actionable business insights.

---

## 🛠️ Tools Used
* **Power BI Desktop**: For data modeling, cleaning, and creating interactive visualizations/dashboards.
* **GitHub**: For project documentation and hosting files.

---

## 📊 Key Findings & Insights
1. **Furniture Loss/Low Profit**: Despite high sales volume in the Furniture category, profit margins are notably low, with some regions experiencing losses.
2. **Discount Impact**: Offering discounts above 20% consistently leads to negative profits (losses), highlighting the need for stricter discount management.
3. **Regional Performance**: The West and East regions generated the highest overall revenue, while performance in the Central region lagged behind.
